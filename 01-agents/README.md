# 01 — Agents

Five agent roles, each with distinct responsibilities in the research vault ecosystem.

## Agent Roles

| Agent | Model | Primary Role |
|-------|-------|--------------|
| **Admin** | Claude Code (Opus) | Team coordination, memory gatekeeping |
| **MA** | Codex CLI (GPT-5.4 medium) | Market analysis, trend synthesis |
| **FA** | Claude Code (Sonnet) | Research analysis, documentation |
| **IS** | Claude Code (Sonnet) | Intelligence gathering, source verification |
| **Ops** | Claude Code (Sonnet) | Workflow automation, process optimization |

## Admin

`Admin/config.md` — Team leader. Holds final write authority on restricted memory tiers.

## MA (Market Analyst)

`MA/config.md` — Specializes in quantitative market analysis. Synthesizes trends from public data feeds.

## FA (Research Analyst)

`FA/config.md` — Focuses on qualitative research. Handles documentation, citations, and paper writing.

## IS (Intelligence Specialist)

`IS/config.md` — Gathers and verifies information from external sources. Cross-references claims.

## Ops (Operations)

`Ops/config.md` — Manages automation scripts, sync pipelines, and workflow triggers.
