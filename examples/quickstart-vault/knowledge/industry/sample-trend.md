# Persistent memory becomes table stakes

Vendors shipping AI agents in 2026 are converging on local-first
persistent memory as the default, not a premium feature. The
differentiator is moving from "do you have memory" to "what does your
decay curve protect against".

Three shifts visible in the last quarter:

1. Memory is now a substrate, not a product surface.
2. Decay policy is the new schema decision.
3. Write-gate review (agent → admin → researcher) is being treated as a
   safety property, not a workflow nicety.

Industry note — `difficulty: 2.0`, ~6 day half-life.
