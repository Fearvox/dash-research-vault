# Restricted Memory

**Admin-only access tier.** All writes require review gate.

## Subdirectories

- `relationship/` — Stakeholder maps, contact networks
- `risk/` — Risk assessments, due diligence files
- `evolution/` — Self-evolution tracking and pressure calibration logs

## Write Protocol

1. Agent drafts in `public/`
2. Submits to `#internal` for review
3. Admin approves and moves to restricted tier
4. Entry tagged with difficulty=2.5–4.0

## Access Log

All reads and writes are logged to `.meta/access-log.jsonl`

---

*Unauthorized access is prohibited. Access is granted via Admin role only.*
